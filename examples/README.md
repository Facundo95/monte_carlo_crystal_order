# Examples

This section contains ready-to-use example inputs for the Monte Carlo code. Each folder shows a different physical setup and includes the files needed to run a sample simulation.

## `ising`

The `ising` folder contains an example based on the Ising model. It provides a spin-based configuration together with the corresponding input file, so you can test a magnetic simulation with a minimal setup.

## `beg`

The `beg` folder contains an example for the BEG (Blume-Emery-Griffiths) model. It includes a sample lattice configuration and input data for simulations that combine magnetic and structural degrees of freedom.

Use these folders as references when preparing your own runs or when checking the expected file format for each model.
